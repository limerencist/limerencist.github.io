MacOS 使用備忘

更新於2026-05-23|devops
|字數統計:3.3k|閱讀時間:11分鐘|瀏覽量:

  入職新公司後，直接領了一臺 MacBook Pro，導致以後的工作少不了在 MacOS 上開展，和以前經常在 Windows 和 Linux 上的操作習慣就很不一樣。故此，記錄一下操作和相關軟件的選取。

Terminal

 自從發現 starship 和 fish 之後，只要是 Unix/Linux 環境，我都會第一時間安裝：starship 負責好看，fish 負責好用，好看又好用，越用越覺得實用。

starship

fish

  fish 作為一種好用的 shell ，內置了很多快捷操作，比如命令/參數/選項完全自動提示和補全（zsh 下則需要安裝插件），切換目錄時直接輸入目錄名稱而無需再輸入 cd 等，尤其喜歡的則是命令縮冩。

  作為一個懶人，我之前最常用的操作就是通過 alias 命令將很長的命令進行別名簡化，比如 alias di="docker images|grep -v REPOSITORY|sort -n" ，這樣一來只需要執行 di 而不用那一長串就可以查看並排序 docker 鏡像。效率確實提高不少，可也帶來兩個問題———一個是別名用久，忘記原來命令是什麼；二來這個別名只有自己知道，別人並不瞭解這個縮冩代表什麼。如果說人還能通過執行的結果反推命令的話，那麼通過 history 查詢裡看到的也只是別名。

  fish 的命令縮冩則採取另一種實現方式，配置的命令改成 abbr di "docker images|grep -v REPOSITORY|sort -n"：從表面上和 alias 一樣簡化命令，當在終端輸入 di 時，不單單隻顯示 di ，而是自動把 di 補全成配置的完整的命令。怎麼樣？是不是完全解決上面說的兩個問題，而且並沒有改變輸入方式，照樣可以偷懶。當然，如果不用 fish，普通的 shell 也能實現該功能：安裝 abbrev-alias 就行，設置和普通的 alias 幾乎一樣。

  誠然，fish 很好用，但為此付出相應的代價就是不支持某些原生 bash 語法或者常用操作， 比如我之前常用 ！+命令 來執行上一次執行過的相同命令，fish 裡就不行，但考慮到其本身的自動提示已經很完善，所以影響也不大。

Music

Spicetify

  雖然咱工作上投靠了蘋果，但是聽音樂可不用 Apple Music，畢竟收錢才能用不符合我窮鬼的身份。而鼎鼎大名的聲破天 Spotify 誰用誰知道——不能說完全免費，不過人家不像蘋果，沒有收費的使用門檻，就是功能上有些閹割。比如廣告——畢竟產品要賺錢嘛，這沒辦法；又比如限制了切歌次數和播放模式（單曲循環），當然這個限制據我的觀察好像只在移動端才有，PC端基本沒限制。除此免費功能之外，Spotify 本身不如 Apple Music 的地方，主要也就是在歌詞數量和播放界面的美觀度上有所欠缺。這不，輪到我們的主角 spicetify 登場了。

 spicetify 是一個開源項目，它允許用戶自定義 Spotify 客戶端的外觀和功能。通過 spicetify，你可以修改 Spotify 的界面、主題、功能等，不僅比 Apple Music 好看，還能更加個性化。同時支持 macOS、Windows 和 Linux 主流操作系統，並且有豐富的主題和插件可供選擇。聽起來是不是很不錯，符合我們技術人的身份。愛他，就折騰他！

歌詞展示

  俗話說得好，沒有歌詞的音樂就像沒有靈魂的軀殼。即使已經通過 spicetify 美化了播放界面，軟件內部的歌詞來源也變多了，但是在外部的歌詞顯示上還是有些不足，畢竟大多數情況下不會一直盯著播放界面。而在其他音樂軟件上早就有的桌面欄歌詞或者 MacOS 的靈動島歌詞功能，不知道為什麼 Spotify 的開發者或者產品經理始終無動於衷，遲遲沒有實現。不怕，人類自古以來就是善於藉助工具的力量來解決問題。

Dynamic Lyrics

  也許是 MacOS 的生態確實龐大，又或者是 Apple Music 的界面設計確實深入人心，很多開發者都願意做歌詞展示相關的工具，我之前用是 LyricX，可以自己重新搜索歌詞，也支持多個歌詞顯示方式，就是效果確實簡陋一點。現在我用的則是 Dynamic Lyrics ，界面就美觀多了，並且也可以當作小組件使用。缺點就是靈動島歌詞的顯示小了一點，而且不可以調整。

Lyricify

  在 Windows 上的 Lyricify 則不一樣，我覺的稱他為王者也毫不過分。專注於歌詞展示的意思，就是將歌詞展示到了極致，支持多種顯示方式，包括桌面歌詞、任務欄歌詞、靈動島歌詞等，完美彌補了上述的缺憾。為防劇透，具體效果還是得自己使用才知道。

常用軟件

 這邊主要就是列出一些日常使用中覺得不錯的軟件，當然每個人的習慣不同，所以僅供參考——最主要的原因，還是我是窮鬼。

  • Shottr：完爆系統自帶的截圖快捷鍵。
  • Rectangle：夢迴 Windows 的窗口管理。
  • Raycast：無論是內置的功能還是可拓展的插件都很強大的全方面六邊形搜索工具。
  • AIDente：電池管理工具，據說很有用，但實際是否真的有用，我其實也看不出來。
  • Easydict：支持多個翻譯源和翻譯方式的翻譯工具，大多數情況下非常好用，除了偶爾會誤觸發翻譯。
  • Input Source Pro：AI 驅動的針對不同應用的輸入法切換工具，一會兒冩代碼，一會兒執行命令，一會兒聊天搜索，自動切換，免除後患。
  • Runcat：誰能拒絕一隻可愛的小貓在任務欄跑來跑去呢？而且還能顯示當前CPU、內存、網絡等信息，非常實用，缺點是隻能在 App Store 下載。
  • Hidden Bar：隱藏狀態欄應用圖標神器，我早期用的多，現在我從根本上把需要顯示在狀態欄的應用圖標減少到極致，已經很乾淨了，就不再使用。
  • AppGridMac：MacOS 向 Windows 學習了，把原本的 Launchpad 改成了現在這樣，而且還不能隱藏那些基本用不到可又卸載不了的系統應用，真個界面亂嘈嘈。我還是更喜歡全屏的——用它。
  • Terminus：相較於 iTerm2 這種需要手動配置才能實現美化的終端，Terminus 直接提供了豐富的主題和配置選項和更多實用的功能，非常適合我這種經常操作服務器的技術人員，且支持多操作系統。
  • Tencent Lemon：系統清理工具，界面簡潔，沒有廣告，乾淨得都不像是騰訊會做的產品。沒辦法，MacOS 上其他口碑較好的清理工具，絕大多數都是收費買斷。我用它也就是圖個方便，最主要還是卸載軟件。
  • Karabiner-Elements：鍵盤映射工具，起因是我想按 Command 組合快捷鍵，實際外接的機械鍵盤經常誤觸Alt鍵，後來我發現 Alt+一些字母，都是些蘋果為了全球通用而設計的一些國人八輩子完全不會輸入的特殊字符，於是就用這個工具將它們映射成我需要的鍵位，比如將 Alt+S/C/V/F/X/Z/Tab 統統映射成 Command+S/C/V/F/X/Z/Tab，媽媽再也不用擔心我會誤觸按鍵了。
