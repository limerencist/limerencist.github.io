很久之前就是用 Hexo 部署了自己的博客，而想当初选择 Hexo 的原因，详见 搭建Hexo博客，但是最近发现有点太硬核，不是说 Hexo 本身变得复杂，而是整个博客发布的模式过于繁琐。我现在的模式是：

  1. 本地 git clone 了 hexo 的博客目录
  2. 使用 vscode 打开整个目录，新建 md 文件
  3. marktext 新建编辑 md 文件，最后使用 vscode 对比 源文件和渲染后的文件 检查是否格式错误
  4. vscode 打开终端使用 hexo s/hexo d/hexo /g 检阅并推送、部署

有没有什么方法可以简化一下流程，解放我的双手和键盘呢？

强大的互联网上当然是什么都有，所以我推荐 Hexon 和 Qexo，废话不多，开干！

Hexon

打开官网，根据 ReadMe 一通安装、配置的操作后，直接打开 Hexon 的后台管理页面
