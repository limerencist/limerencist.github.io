用 Hexo 怎麼能少了插件？

更新於2023-01-10|devops
|字數統計:815|閱讀時間:3分鐘|瀏覽量:

 在上一篇 搭建 Hexo 博客 中，發佈 Github Page 時用到了 hexo-deployer-git 插件，這裡再介紹一些其他插件。可能大多數主題裡已經包含了，本著“知其所以然”的態度，也稍稍探究一下。

 以下插件主要分為即用型和改造型，前者下載插件加以簡單配置後就可以直接使用；後者還需要修改前端頁面代碼的內容，我還沒有這個實力，推薦給比較硬核的玩家，或者直接使用已經包含插件的主題。

即用型

更換 markdown 渲染器

更換渲染器的原因，是我在按照語法編輯文檔後，發現頁面沒有顯示對應的效果，而是源代碼或者標籤，比如縮進兩字符、文本右對齊、字體顏色等。參考大佬的博客 Hexo 多種 Markdown 渲染器對比分析 後，選用了 hexo-renderer-markdown-it-plus 渲染器，完美實現預期的效果。
