TUI 工具新出路

更新於2026-06-09|dev
|字數統計:2.8k|閱讀時間:11分鐘|瀏覽量:

  說起珍珠奶茶，各位肯定都不陌生，畢竟現在奶茶已經被玩出了花，人手一杯且口味各異；但要說到 Github 界的珍珠奶茶，那不得不提 Bubble Tea —— 一個好看又好用的終端命令行框架。

  之所以注意到這個項目，是因為我主要都是用go語言冩一些命令行工具，如果本身的功能不復雜，那當然怎麼簡單怎麼來；如果功能複雜一些，那作為使用者，我肯定想好用又好看，好看才能促使我多用。而且，一般來說，命令行工具都是簡陋的，既然有一個項目可以讓我們冩出好看又好用的命令行工具，那為什麼不試試呢？

  由於是剛接觸項目實踐一下，這裡就所以只實現了簡單的CPU和內存監控，先探一探這套玩意兒的使用方式。

bubbletea

  在看代碼之前，最好需要理解一下 MVU (Model-View-Update) 的 3 個核心概念：

  • Model（模型）： 你的數據源，負責 _存_；
  • Update（更新器）： 數據如何流轉和更新，負責 _變_；
  • View（視圖）：展示數據，負責 _畫_；

Update

View

main

  之前我通過 Kubebuilder 開發的 CRD 還有印象嗎？為了好理解，可以做個類比，整個過程就是 K8s 的循環協調：

  • Model 好比定義的 yaml；
  • Reconcile 就是 Update，這個過程中肯定有資源變動，比如更新鏡像，對應 tea.Msg；響應操作，比如創建 pod，對應 tea.Cmd；doTick 就是 Update 的推手，一個異步的執行器；
  • K8s 裡最終的結果就是 View 渲染出的界面；

  現在這個程序程序就像是一個狀態機：

  1. 等待消息（空閒）；
  2. 收到消息（CPU / Mem 變了）；
  3. 計算新狀態（Update 運行）；
  4. 重新繪圖（View 運行）；
  5. 回到步驟 1；

vhs

  程序冩完，肯定是要展示效果的，最好是從運行到結束，雖然我本地固然可以執行 go run main.go 。錄頻肯定可以，但一共幾秒的操作，錄個視頻怎麼也得幾十兆大小，不划算且沒有必要；退而求之，那就是 gif 動圖，做動圖有需要專門的工具，有沒有簡單好用的呢？
   Bubble Tea 的開發者 Charm 顯然是有心的，我剛打了瞌睡就發現他們送來枕頭！有個叫做 vhs 的項目，就是專門處理這類問題的。只需要冩個 .tape 小腳本，就能像個導演一樣，定義你想要的動態效果。比如我現在的腳本 btea.tape 如下：

  • Output : 明顯就是輸出文件和格式，也可以是 mp4
  • Set：也很明顯，定義大小、樣式和主題
  • Type：模擬輸入打字
  • Enter：回車
  • Sleep：等待

  運行的話，只需要執行 vhs btea.tape 就行，讓我們來見證奇蹟吧：

  如何，效果還不錯吧？而且，用冩腳本的方式來做動圖或者錄視頻，想想就覺得硬核，符合我技術人的身份！

gum

  好奇的朋友肯定發現了，上面的錄製腳本中有一個 gum 的東西沒見過，不過看動圖裡的效果，感覺有點東西。

  確實，這玩意兒也是一家的，作用就是執行單純的命令或者腳本的時候，也能顯示出對應的組件樣式。對頭，Bubble Tea 是在程序裡用，如果不想冩程序，比如有時候冩 shell 腳本確實更直接，但又想用好看的組件，不至於讓腳本執行的機械感和冰冷感太強，那就用 gum ！

  之前的 gum style 只能算是小試牛刀（黃章：魅族15只是我的小試牛刀——魅族現在涼了，不由地唏噓一下），我們來真正感覺一下它的魅力！

  這個腳本是我之前嫌棄 linux 上默認的 systemctl 命令太長不夠簡單有效，就重新封裝一下；現在用上 gum 的一些組件(考慮到介紹組件最好直接看動態效果，這裡就不贅述了，可以直接訪問 github )，二者一拍即合，就成了現在這幅模樣。當然，在執行腳本之前，我還通過 shc 打包了腳本。

  是時候展現正真的技術了！翠花，上效果圖（媽媽再也不用擔心我輸錯命令和服務名啦）！解放鍵盤，只需要方向鍵+回車！

  和之前稍微不同的是，這個動圖並沒有通過 vhs 完成。慢著，之前剛介紹過怎麼現在不用了呢？原因是這樣的，vhs 說到底還是錄製工具，需要記錄屏幕的像素點並計算，還依賴顯卡驅動、瀏覽器、編碼器（FFMPEG）等組件，如果在我本地，用的效果當然好；但是這個腳本是運行在服務器上的，服務器上一般絕對不會安裝這些工具，所以我才用 Asciinema 這種偽終端模式，它的文件名格式是 .cast ，打開的話發現裡面就是 時間+事件 的內容，對服務器來說十分友好和輕量。當我需要錄製時，輸入 asciinema rec sssm.cast ，結束時輸入 Ctrl+D 或者 exit，再在我本地通過 agg sssm.cast sssm.gif 進行轉換。步驟多了，效果依舊槓槓滴！

Charm

   看了 Charm 的官網，不得不說他們的風格真的有點少女心；為了終端好看又好用，真是操碎了心，各個組件包含各個使用場景。即使用了以上的內容，也僅僅是全家桶的裡一部分。他們來得及開發，我也來不及用啊，只能需要時候再說。
